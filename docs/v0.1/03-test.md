# v0.1 테스트

## 가짜 데이터 테스트

사람인 API, LLM, 구글 시트를 가짜 함수로 바꾸고 그래프 전체를 실행했습니다.

| 확인 항목 | 결과 |
| --- | --- |
| fetch → summarize → save 순서대로 실행 | 통과 |
| 시트에 넘기는 값이 회사명, 직무, 자격요건, 마감일, 링크 순서 | 통과 |
| 사람인 응답 JSON → 마감일 날짜 변환 | 통과 |
| `LLM_MODEL`로 Gemini, Claude 모델 객체 생성 | 통과 |

이 테스트는 아직 저장소에 파일로 들어 있지 않습니다. v0.2에서 `tests/`에 pytest로 추가합니다.
