# v0.1 요구사항

> v0.1은 구현 후에 문서를 정리했습니다. v0.2부터는 이 문서를 먼저 쓰고 구현합니다.

## 목표

키워드 하나로 사람인 공고 1건을 가져와, AI로 자격요건을 한 줄 요약하고, 구글 시트에 한 줄 저장한다.

## 기능 요구사항

| ID | 내용 |
| --- | --- |
| F1 | 실행할 때 검색 키워드(필수)와 지역 코드(선택)를 입력받는다 |
| F2 | 사람인 오픈API에서 최신 공고 1건을 가져온다 |
| F3 | LLM으로 자격요건을 60자 이내 한국어 한 줄로 요약한다 |
| F4 | 구글 시트에 회사명, 직무, 자격요건, 마감일, 링크를 한 줄 추가한다 |
| F5 | 시트에 제목 줄이 없으면 먼저 넣는다 |

## 비기능 요구사항

| ID | 내용 |
| --- | --- |
| N1 | API 키는 코드가 아니라 `.env`에만 두고 GitHub에 올리지 않는다 |
| N2 | 무료로 개발할 수 있어야 한다 (기본 모델 Gemini 무료 구간) |
| N3 | 설정 한 줄로 AI 모델을 바꿀 수 있어야 한다 (Gemini ↔ Claude) |
| N4 | 백엔드 서버 없이 파이썬 스크립트 하나로 실행된다 |

## 하지 않는 것

- 여러 공고 수집, 중복 저장 방지
- 이력서 기반 적합도
- 웹 화면
