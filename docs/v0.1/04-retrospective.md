# v0.1 회고

## 바뀐 결정

- AI 모델을 Claude에서 Gemini로 변경: Anthropic API는 무료 구간이 없어 개발 비용을 줄이기 위해. 설정으로 언제든 되돌릴 수 있게 함.
- 구글 시트 연동은 MCP 대신 gspread로 시작: 입문 단계 단순화.

## 배운 점

- Gemini 2.5는 내부 추론(thinking) 토큰도 출력 한도에 포함되어, 한도를 작게 잡으면 빈 응답이 올 수 있음. 그래서 `max_tokens=1024`로 둠.
