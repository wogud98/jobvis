| 버전 | 목표 |
| --- | --- |
| v0.1 | 공고 1건 → AI 요약 → 시트 1줄 (최소 동작) |
| v0.2 | 여러 공고 수집, 필터(지역·직무·경력), 중복 저장 방지 |
| v0.3 | 수집과 평가 두 단계로 분리, 적합도 점수·별점·강점·부족한 점, 스킬 갭 분석 |

| v0.5.1 | 화면 개선: 사용법 토글, 요약 칸, 프로필 고르기 입력, 벤토 그리드 + 글래스모피즘 테마 (v0.5 사용 피드백) |
| v0.6 | AI 직무 추천 (적합도 결과를 바탕으로) |
| v0.7 | 매일 아침 추천 공고 정리본 메일 발송 |

| 보류 | FastAPI로 기능 감싸기 |

## 결정 사항

2026-10-19 결정, 2026-10-20 갱신(v0.4 공고 출처 변경 포함), 2026-10-21 갱신(v0.5 프로필 입력 추가, 이후 버전 한 칸씩 밀림. FastAPI 보류, Streamlit 화면을 v0.5로). 바뀌면 이 표를 갱신하고 이유를 해당 버전 회고에 남깁니다.

| 항목 | 결정 | 반영 버전 |

| 프로필 입력 | `profile.yaml`로 받고 점수 항목과 칸을 맞춤. 화면 프로필 탭에서 입력(경력 슬라이더), 파일을 직접 고쳐도 됨 | v0.5 |

| 결과 받는 곳 | 구글 시트 + 매일 아침 추천 공고 정리본 메일 | 시트 v0.1, 메일 v0.7 |

## 화면 참고

2026-10-19 사용자 요청. v0.5에는 경력 슬라이더(프로필 탭)만 넣고, 나머지는 화면을 써 보면서 다음 버전 요구사항에 반영한다.

- 키워드, 지역, 직무를 입력할 때 추천 검색어가 떠서 고를 수 있게 한다.
- 경력은 가로 슬라이더로 고른다. 사람인 응답의 연차(`experience-level`의 `min`·`max`)와 맞춘다.
- 여유가 되면 공고별 적합도를 레이더 차트(항목별 다각형)와 숫자로 함께 보여준다. 2026-10-20 사용자 요청.
