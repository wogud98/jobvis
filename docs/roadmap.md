# 로드맵

큰 방향만 여기서 정하고, 세부는 각 버전의 요구사항 문서에서 정합니다.

| 버전 | 목표 |
| --- | --- |
| v0.1 | 공고 1건 → AI 요약 → 시트 1줄 (최소 동작) |
| v0.2 | 여러 공고 수집, 필터(지역·직무·경력), 중복 저장 방지 |
| v0.3 | 적합도 점수와 이유 (기준은 v0.2 완료 후 결정) |
| v0.4 | AI 직무 추천 (적합도 결과를 바탕으로) |
| v0.5 | 매일 아침 추천 공고 정리본 메일 발송 |
| v0.6 | 시트 연동을 MCP로 전환 |
| v1.0 | FastAPI로 기능 감싸기 + Streamlit 웹 화면 |

## 결정 사항

2026-10-19 결정. 바뀌면 이 표를 갱신하고 이유를 해당 버전 회고에 남깁니다.

| 항목 | 결정 | 반영 버전 |
| --- | --- | --- |
| 화면 | 기능 완성까지 터미널, 이후 웹 화면 | v1.0 |
| 공고 거르는 기준 | 지역 + 직무 + 경력. 지역·직무는 사람인 API 조건, 경력은 API에 조건이 없어 받은 공고에서 프로그램이 거름 | v0.2 |
| 적합도 기준 | 기본 기능 구현 후 결정 (후보: 이력서와 AI 비교, 키워드 일치 개수) | v0.3 |
| AI 직무 추천 | 넣음, 적합도 다음 버전에 | v0.4 |
| 결과 받는 곳 | 구글 시트 + 매일 아침 추천 공고 정리본 메일 | 시트 v0.1, 메일 v0.5 |

## 웹 화면(v1.0) 참고

2026-10-19 사용자 요청. v1.0 요구사항을 쓸 때 반영한다.

- 키워드, 지역, 직무를 입력할 때 추천 검색어가 떠서 고를 수 있게 한다.
- 경력은 가로 슬라이더로 고른다. 사람인 응답의 연차(`experience-level`의 `min`·`max`)와 맞춘다.
