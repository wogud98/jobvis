# 로드맵

큰 방향만 여기서 정하고, 세부는 각 버전의 요구사항 문서에서 정합니다.

| 버전 | 목표 |
| --- | --- |
| v0.1 | 공고 1건 → AI 요약 → 시트 1줄 (최소 동작) |
| v0.2 | 여러 공고 수집, 필터(지역·직무·경력), 중복 저장 방지 |
| v0.3 | 이력서 기반 적합도 점수와 이유 |
| v0.4 | 시트 연동을 MCP로 전환 |
| v1.0 | FastAPI로 기능 감싸기 + 웹 화면 |

## 정해야 할 것

사용자 결정을 기다리는 항목입니다. 정해지면 이 표를 갱신하고 해당 버전 요구사항에 반영합니다.

| 항목 | 선택지 | 결정 |
| --- | --- | --- |
| 화면 | 터미널 후 Streamlit / 처음부터 웹 | 미정 |
| 공고 거르는 기준 | 지역+직무+경력 / +학력·고용형태 | 미정 |
| 적합도 기준 | 이력서와 AI 비교 / 키워드 일치 개수 | 미정 |
| AI 직무 추천 | 적합도 다음 버전에 추가 / 제외 | 미정 |
| 결과 받는 곳 | 구글 시트만 / 시트 + 메일 알림 | 미정 |
