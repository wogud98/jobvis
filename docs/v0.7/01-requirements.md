# v0.7 요구사항

초안(2026-10-22). 재리 "선택 공고 보내기 먼저" → "진행". 확정 전.

화면에서 고른 공고를 내 메일로 보낸다. 매일 아침 자동 발송은 하지 않는다(각자 PC에서 돌아서 그 시간에 PC·Docker가 켜져 있어야 함, 서버 단계 후보로 남김).

## 목표

1. 공고 목록에서 몇 건을 골라 버튼 하나로 내 메일함에 보낸다. 휴대폰에서 메일로 다시 본다.
2. 메일에는 공고를 고를 때 필요한 것만 담는다(회사·직무, 점수·판정, 마감, 강점·부족한 점 한 줄, 원문 링크).
3. 메일 계정 설정은 키 넣기처럼 화면에서 한 번만 한다. 비밀번호는 PC 안에만 둔다.

## 사용자 결정 (2026-10-22)

- "메일 알림도 구현하자. 사용자가 선택한 공고를 보내는 기능이나, 매일 아침 신규 공고를 보내주거나" → 제안(선택 공고 먼저, 매일 아침은 서버 단계) → "선택 공고 보내기 먼저"
- 제안(창에서 고르기, Gmail 앱 비밀번호, 시험 메일, 메일 v0.7·추천 v0.8) → "진행"

## 사용 흐름

1. 화면 위 **✉ 메일** 버튼 → 처음이면 메일 설정 창(Gmail 주소, 앱 비밀번호, 받는 주소). **시험 메일 보내기**로 확인하고 저장.
2. 다시 **✉ 메일** → 보내기 창. 지금 목록(사이드바 필터 적용)의 공고가 체크 칸과 함께 보인다.
3. 공고를 고르고 **보내기** → "n건을 보냄" 알림.

## 기능 요구사항

### 고르기·보내기

| ID | 내용 |
| --- | --- |
| F1 | 화면 위에 **✉ 메일** 버튼. 메일 설정이 없으면 설정 창, 있으면 보내기 창을 연다 |
| F2 | 보내기 창은 지금 목록(필터·정렬 적용, 관심 없음 제외)의 공고를 회사·직무·점수와 체크 칸으로 보인다. 처음엔 아무것도 고르지 않음. "보이는 공고 모두 고르기"가 있다 |
| F3 | 한 번에 최대 30건. 넘게 고르면 보내기 버튼이 눌리지 않고 이유를 보인다. 0건이어도 눌리지 않는다 |
| F4 | 보내면 "n건을 보냄 (받는 주소)" 알림. 실패하면 창에 할 일만 보인다(F9) |

### 메일 내용

| ID | 내용 |
| --- | --- |
| F5 | 제목: `[JOBVIS] 공고 n건 (YYYY-MM-DD)` |
| F6 | 본문은 HTML과 글자만 있는 판 두 가지. 공고마다 회사·직무(원문 링크), 종합점수·판정, 마감(D-n), 출처·경력, 강점 한 줄·부족한 점 한 줄. 평가 전 공고는 "평가 전"으로 |
| F7 | 시트·DB의 글자는 HTML로 넣기 전에 escape. 원문 링크는 http(s)만 |

### 메일 설정

| ID | 내용 |
| --- | --- |
| F8 | 설정 창: 보내는 Gmail 주소, 앱 비밀번호(16자리, 가려서 입력), 받는 주소(기본은 보내는 주소). 앱 비밀번호 만드는 곳 링크와 "Google 2단계 인증이 켜져 있어야 함" 안내. 저장하면 키처럼 `data/settings.env`에만 쓰고 화면에는 끝 4자리만. **시험 메일 보내기**와 **이 PC에서 메일 설정 삭제** |
| F9 | 오류는 할 일만: 비밀번호 틀림 → "Gmail 앱 비밀번호가 맞지 않습니다. 앱 비밀번호를 다시 만들어 넣어 주세요", 연결 실패 → "메일 서버에 연결하지 못했습니다. 인터넷 연결을 확인해 주세요", 받는 주소 형식 틀림 → 저장 전에 막음 |

## 비기능 요구사항

| ID | 내용 |
| --- | --- |
| N1 | 새 의존성 없음. 파이썬 기본 `smtplib`·`email`로 `smtp.gmail.com:465`(SSL) |
| N2 | 앱 비밀번호는 로그·예외 문구·화면·이미지·저장소에 나오지 않는다(`settings.redact`에 포함). `.gitignore`·`.dockerignore`의 `data/` 안에만 저장 |
| N3 | 테스트는 실제 메일을 보내지 않는다. SMTP를 가짜로 바꿔 보낸 내용(제목·받는 주소·본문·escape)과 실패(인증 오류, 연결 오류, 0건, 30건 초과)를 확인한다 |
| N4 | 메일 보내기는 수집·평가 실행 중에도 된다(LLM·사이트 요청 없음) |

## 하지 않는 것

- 매일 아침 자동 발송, 새 공고 알림(예약 실행). 서버 단계 후보로 로드맵에 남김
- Gmail 말고 다른 메일(네이버 등). 필요하면 다음 버전 후보
- Google 로그인(OAuth). 앱 비밀번호보다 설정이 훨씬 복잡함
- 보낸 기록을 시트·DB에 저장
- 터미널(`main.py`)에서 보내기

## 정할 것

- 버튼 위치: 화면 위(🔑·📖 옆) 추천. 사이드바 아래도 가능
- 보내기 창에서 고르는 목록: 지금 목록(필터 적용) 추천. 전체 공고에서 검색해 고르는 방식도 가능
