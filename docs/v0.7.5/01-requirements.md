# v0.7.5 요구사항

2026-10-27 확정(재리 "진행" 08:12). 이미 모은 공고를 사이드바에서 지역으로 거른다. 수집·평가·저장 칸은 바꾸지 않는다.

## 사용자 의견과 결정

- "지역 필터가 없네"(08:09) → 수집 카드의 지역은 사이트에서 가져올 때만 거르는 조건. 사이드바 필터에는 지역이 없었음. 공고마다 지역 칸은 이미 저장돼 있음
- 내 안: 출처와 경력 사이에 "지역" 고르기 칸, 시·도 단위로 묶음, 빈 칸은 "미상"(제안 → "진행")

## 기능 요구사항

| ID | 내용 |
| --- | --- |
| F1 | 사이드바 필터의 출처와 경력 사이에 "지역" 고르기 칸. 처음엔 비어 있고 "전체"로 보인다. 보기는 지금 공고에 있는 묶음만, 정해진 순서(프로필 희망 지역 순서 → 전국 → 기타 → 미상). 여러 개 고를 수 있고 다른 필터와 함께 걸린다 |
| F2 | 지역 글자의 첫 낱말로 시·도 묶음을 정한다. "서울 강남구 외 1" → 서울, "서울특별시"·"경상남도" 같은 긴 이름도 묶음으로. 빈 칸은 "미상", 못 묶으면 "기타" |
| F3 | 기술 모아보기·메일 창 위 켜진 필터 이름에 "지역 서울·경기"처럼 보인다 |

## 비기능 요구사항

| ID | 내용 |
| --- | --- |
| N1 | 새 의존성 없음. 지역 묶기는 `agent/view.py`(Streamlit 없이 테스트) |
| N2 | 수집 카드의 지역, 명령줄 `--location`, 저장 칸은 그대로 |

## 하지 않는 것

- 구·시 단위 필터(보기가 너무 많아짐, 미니멀 원칙)
- 잡코리아 "외 1"의 다른 지역(목록에 첫 지역만 나옴)
- 반복 수집 때 중복 뺀 뒤 개수 채우기(수집 흐름 변경이라 따로)
