# v0.5.3 요구사항

2026-10-22 확정. 공고 화면을 읽기 쉽고 고르기 쉽게 바꾸고, 다크 모드를 넣는다. 수집·평가 방식과 점수 계산은 바꾸지 않는다.

## 목표

1. 카드 "자세히"를 훑어보기만 해도 점수 근거(항목 점수, 강점, 부족한 점)가 보인다.
2. 마감, 새 공고, 지원 여부를 카드에서 바로 알고, 검색으로 공고를 찾는다.
3. 밝은 화면과 어두운 화면을 모두 쓸 수 있다.

## 사용자 의견 (2026-10-22)

- "공고의 자세히 내용 보기가 어려움(단순 텍스트 나열이라서)"
- "문화의 경우 없는 곳이 많다 보니 아예 제외하는 것이 어떤지?"
- "평점은 각 기술 경력 방향은 0–100점 범위인지?"
- "다른 사용자 편의성을 증가시킬 방안 제시해도 좋다"

제안(자세히 개편, 점수 기준 안내, 문화는 화면에서만 숨김, 마감 표시, NEW, 검색, 지원함, 카드 머리 강점)에 "모두 반영하자. 그리고 다크 모드도 만들자"로 확정.

## 기능 요구사항

### 자세히 (평가한 공고)

| ID | 내용 |
| --- | --- |
| F1 | 맨 위에 항목 점수(기술·경력·문화·방향)를 이름, 막대, 숫자로 보인다. 막대 색은 70 이상 초록, 40–69 노랑, 40 미만 빨강 |
| F2 | 그 아래 두 칸: 왼쪽 "✅ 강점", 오른쪽 "⚠️ 부족한 점". 각 항목은 글머리표 |
| F3 | 요약·주요업무·우대사항은 글머리표 목록으로 보인다. 쉼표, 줄바꿈, 앞뒤를 띄운 " · "와 " / "로 나눈다("Python·SQL"처럼 붙은 것은 나누지 않음). 비면 그 칸은 안 보인다 |
| F4 | 기술스택은 칩으로 보인다. 내 프로필(주력 기술, 다룰 수 있음)에 있는 기술은 초록 칩, 없는 기술은 흰 칩. 대소문자·공백은 무시하고 비교한다 |
| F5 | 맨 아래 접힌 "점수 기준"에 적는다: 항목 점수는 0–100, 종합점수는 기술 30·경력 25·문화 15·방향 30 가중 평균(근거 없는 항목은 빼고 나머지로 나눔), 별점은 종합점수 20점마다 1개, 경력이 부족하면 종합 최대 79, 본문 없이 매기면 최대 69. 숫자는 코드 상수에서 가져온다. 신뢰·보정은 그 위에 작게 |
| F6 | 문화 점수는 근거가 있을 때만 보인다(막대·글자 모두). 점수 계산은 바꾸지 않는다 |

### 카드 머리

| ID | 내용 |
| --- | --- |
| F7 | 마감까지 7일 이하면 "D-n"(당일은 "D-day") 빨간 배지. 마감이 지났으면 "마감" 배지와 카드를 흐리게. 상시·빈칸은 배지 없음 |
| F8 | 정렬에 "마감 임박 순"을 더한다: 남은 마감일 순, 그다음 상시·빈칸, 맨 뒤 지난 공고. 점수 있는지와 상관없이 정렬한다 |
| F9 | 화면을 마지막으로 연 뒤 시트에 새로 저장된 공고에 "NEW" 배지. 마지막으로 연 시각은 `data/last_seen.txt`(커밋 안 함)에 두고, 화면을 새로 열 때(세션 시작) 읽은 뒤 지금 시각으로 바꾼다. 같은 세션에서 수집한 공고도 NEW. 파일이 없으면(처음) NEW 없음 |
| F10 | 필터 칸 맨 위에 "검색"(회사명·직무, 대소문자 무시, 부분 일치). 비면 거르지 않는다 |
| F11 | 카드 오른쪽에 "지원함" 버튼. 누르면 시트 맨 끝 새 열 AE "지원"에 쓰고 카드 머리에 "지원함" 배지. 다시 누르면 취소. 쓰기 실패하면 그대로 두고 이유를 보인다. 필터에 "지원한 공고만 보기" |
| F12 | 평가한 공고는 펼치지 않아도 카드 머리에 첫 번째 강점 한 줄("💪 …")이 보인다 |

### 다크 모드

| ID | 내용 |
| --- | --- |
| F13 | 밝은 테마와 어두운 테마를 둔다. 기본은 컴퓨터 설정(시스템 다크 모드)을 따르고, 오른쪽 위 ⋮ → Settings → Theme에서 바꿀 수 있다. 사용법 토글에 이 방법을 적는다 |
| F14 | 어두운 테마도 네오 브루탈리즘(굵은 테두리, 딱 떨어지는 그림자)을 유지한다. 바탕 짙은 회색, 카드 조금 밝은 회색, 테두리·그림자·글자는 밝은 색, 포인트 초록은 밝게(#34d399) |
| F15 | 요약 4칸·배지·막대의 색 면은 두 테마에서 같은 색을 쓰고, 그 위 글자는 늘 검정으로 읽히게 한다 |

## 비기능 요구사항

| ID | 내용 |
| --- | --- |
| N1 | 새 의존성 없음. Streamlit 1.66의 `[theme.light]`·`[theme.dark]` 설정과 `st.context.theme`을 쓴다 |
| N2 | 글 나누기, 기술 비교, 마감 계산, NEW 판단, 검색, 정렬은 Streamlit 밖 `agent/view.py` 함수로 두고 가짜 데이터로 테스트한다. 실제 시트·브라우저 호출 없음 |
| N3 | `data/last_seen.txt`는 `data/`라 커밋되지 않는다. 읽기·쓰기에 실패해도 화면은 뜬다(NEW만 없음) |

## 하지 않는 것

- 화면 안 다크 모드 버튼. Streamlit은 코드로 테마를 바꿀 수 없어 설정 메뉴를 쓴다
- 지원 날짜·지원 상태(서류, 면접) 관리. 지원함 하나만
- 문화 점수를 계산에서 빼기(화면에서만 숨김)
