# v0.5.5 요구사항

2026-10-22 확정. 프로필 탭에서 칸 하나 또는 모든 칸을 화면에서 비울 수 있게 한다. `profile.yaml`은 💾 저장을 누를 때만 바뀐다.

## 사용자 의견 (2026-10-22)

- "프로필 입력에서 각 칸 우측 상단에 새로고침 문양을 남겨서 그 칸만 초기화하는 기능 추가"
- "전체 초기화 버튼 추가"
- "브라우저에 입력된 것만"

제안(칸마다 ↺, 전체 초기화는 확인 창, 이력서로 채운 값도 버림)에 "일단 하던 거 마저 진행"으로 확정.

## 기능 요구사항

| ID | 내용 |
| --- | --- |
| F1 | 프로필 입력란마다 오른쪽 위에 ↺. 누르면 그 칸만 빈 값(목록은 비움, 경력 연수는 0, 학력은 선택 안 함)으로 그린다. 마우스를 올리면 "이 칸 비우기 (저장 전까지 파일은 그대로)". 비운 뒤 적었다가 다시 눌러도 비워진다 |
| F2 | 💾 저장 옆 "전체 초기화". 누르면 확인 창("비우기", "취소")을 띄우고, 비우기를 누르면 모든 칸과 이력서로 채운 값을 비운다. 취소하면 그대로 |
| F3 | 비우기는 화면 입력만 바꾼다. `profile.yaml`은 💾 저장을 누를 때만 바뀌고, 저장하지 않고 화면을 새로 열면 저장된 값이 다시 나온다. 저장하거나 이력서로 채우면 비운 표시는 없어진다 |
