# JOBVIS 개발 문서

JOBVIS는 단계(버전)마다 아래 과정을 반복하며 만듭니다. 각 버전 폴더에 과정별 문서가 한 장씩 있습니다.

| 순서 | 문서 | 내용 |
| --- | --- | --- |
| 1 | `01-requirements.md` | 이번 버전에서 할 일과 하지 않을 일 |
| 2 | `02-design.md` | UML과 설계 결정, 그 이유 |
| 3 | 코드 | 설계대로 구현 |
| 4 | `03-test.md` | 테스트 방법과 결과 |
| 5 | `04-retrospective.md` | 문제, 배운 점, 다음 버전으로 넘길 것 |

UML은 [Mermaid](https://mermaid.js.org)로 작성해 GitHub에서 바로 그림으로 보입니다.

## 버전

| 버전 | 목표 | 상태 |
| --- | --- | --- |
| [v0.1](v0.1/) | 키워드로 사람인 공고 1건을 요약해 구글 시트에 1줄 저장 | 구현 완료, 실제 키로 실행 확인 전 |
| [v0.2](v0.2/) | 여러 공고 + 필터(지역·직무·경력) + 중복 방지 | 구현 완료, 실제 키로 실행 확인 전 |
| [v0.3](v0.3/) | 수집·평가 분리 + 적합도 채점 + 스킬 갭 분석 | 구현 완료, 실제 키로 실행 확인 전 |
| [v0.4](v0.4/) | 사람인·잡코리아 크롤링 수집 (목록 + 상세 본문 + 이미지 OCR) | 설계 확정, 구현 전 |
| [v0.5](v0.5/) | 프로필 입력 형식(`profile.yaml`)과 첫 실행 질문 | 요구사항 확정, 설계 전 |

전체 방향은 [roadmap.md](roadmap.md)에 있습니다.
