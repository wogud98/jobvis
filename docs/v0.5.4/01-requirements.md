# v0.5.4 요구사항

2026-10-22 확정. v0.5.3을 써 본 의견으로 공고 화면의 필터, 자세히, 이미지 넣기 안내, 사용법, 어두운 테마를 고친다. 수집·평가 방식, 점수 계산, 시트 열은 바꾸지 않는다.

## 목표

1. 목록을 내려도 필터를 쓸 수 있고, 요약 칸에서 바로 걸러 본다.
2. 자세히는 필요할 때만 떠 있고, 비교하고 싶은 공고는 열어 둔다.
3. 처음 쓰는 사람도 사용 순서, 신뢰 기준, 이미지 넣는 이유를 안다.
4. 어두운 테마에서도 칸이 구분된다.

## 사용자 의견 (2026-10-22)

- "필터를 화면에 고정해 숨기거나 나타나게 해서 공고 목록이 보이는 곳에서도 볼 수 있게"
- "마감일 기준으로 D-2처럼 며칠 남았는지 표기"
- "자세히 토글은 다른 곳을 클릭하면 닫히고, 열린 상태를 유지하고 싶으면 고정하기 기능도"
- "사용자가 신뢰 기준을 알 길이 없다" → 결정 카드에서 "지금 단어 + 도움말" 선택
- "원문을 읽지 못한(이미지를 직접 올려야 하는) 공고만 볼 수 있게", "업로드 칸이 무엇인지 모를 것 같음"
- "사용법은 새 창을 띄우는 것만 하고 실제 화면에서는 번호를 붙이지 않는다"
- "어두울 때 요약 4칸이 너무 밝으니 톤 다운", "4개 칸을 선택하면 해당 필터가 적용", "숫자 아래 텍스트에 그 기능을 넣어라"
- "어두운 테마는 모두 검정색이라 구분이 어려움"

## 기능 요구사항

### 필터

| ID | 내용 |
| --- | --- |
| F1 | 필터(검색, 출처, 경력, 정렬, 보기 토글)를 왼쪽 사이드바에 둔다. 목록을 내려도 보이고, 사이드바 « 로 접고 펼친다. 맨 위에 "📋 공고 탭 목록에 적용됩니다." 종합점수 TOP 5 차트는 가로 전체 |
| F2 | 토글 "이미지 필요한 공고만 보기": 이미지를 넣을 수 있는 공고(본문 미확보·이미지 일부 못 읽음, 공고 번호 있음)만 |
| F3 | 요약 넷째 칸은 "이미지 필요"로 F2와 같은 기준으로 센다 |
| F12 | 요약 칸 숫자 아래 글("시트에 있는 공고 →" 등)을 누르면 필터를 모두 풀고 그 칸의 필터만 켠다. 전체 공고는 모두 풀기, 평가 완료는 "평가된 공고만 보기", 추천 이상은 새 토글 "추천 이상만 보기"(강력 추천 + 추천), 이미지 필요는 F2. 지금 필터와 같은 칸은 초록 테두리. 글은 마우스를 올리면 밑줄 |

### 카드

| ID | 내용 |
| --- | --- |
| F4 | 마감일이 남은 공고는 모두 D-n(당일 D-day) 배지. 7일 이하 빨강, 넘으면 흰 배지. 지나면 "마감", 상시·빈칸은 배지 없음 |
| F5 | "자세히"는 카드 너비의 떠오르는 창(st.popover). 바깥을 누르면 닫힌다 |
| F6 | 창 맨 위 "📌 펼쳐 두기"를 누르면 그 공고는 카드 안에 펼친 채로 남고 "접기"로 닫는다. 여러 공고를 펼쳐 둘 수 있고 화면을 연 동안 유지된다 |
| F7 | 이미지를 넣을 수 있는 공고는 카드 머리에 노란 "📷 이미지 필요" 배지. 마우스를 올리면 이유 |
| F8 | 이미지 넣는 칸: 제목 "📷 공고 이미지 넣기", 이유 한 줄, 순서 ① 원문 열기 → ② 공고 이미지 저장 → ③ 끌어다 놓고 받은함에 저장 → ④ 받은함 읽기 → ⑤ 다시 평가. 저장 뒤 안내도 화면의 받은함 읽기로 |
| F10 | 신뢰 배지(높음·보통·낮음) 단어는 그대로 두고, 마우스를 올리면 기준이 뜬다: 높음 원문을 다 읽음, 보통 이미지 일부를 못 읽음, 낮음 원문 없이 제목 등만 보고 매김(종합 최대 69점) |

### 사용법

| ID | 내용 |
| --- | --- |
| F9 | 머리의 "📖 사용법" 버튼으로 새 창(st.dialog)을 연다. ① 프로필 저장 → ② 수집 → ③ 평가 → ④ 공고 보기 → ⑤ 이미지 넣기, 그 밖에(새로고침, 다크 모드, 터미널) 순서. 처음 연 화면(지난번 연 기록 없음)에서 한 번 자동으로 뜬다. 화면 구역에는 번호를 붙이지 않고, 탭의 사용법 접기 칸은 없앤다 |

### 어두운 테마

| ID | 내용 |
| --- | --- |
| F11 | 요약 4칸은 어두운 테마에서 같은 색 계열의 짙은 톤(노랑 #5c4a12, 파랑 #1d3f5e, 초록 #1f4d33, 빨강 #5c2626)과 밝은 글자. 밝은 테마는 그대로 |

## 하지 않는 것

- 실제 화면 위 점선 말풍선 안내. Streamlit 밖 JS 도구가 필요하고 화면이 바뀌면 어긋남
- 요약 칸 전체를 누르는 칸으로 꾸미기. CSS로 덮으면 Streamlit 업데이트에 깨지기 쉬워 숫자 아래 글을 버튼으로 함
- 신뢰 단어 바꾸기(사용자 결정: 단어 유지 + 도움말)
