# v0.7.1 요구사항

2026-10-23 확정(재리 "진행"). v0.7을 재리가 써 본 의견으로 화면을 다듬는다. 수집·평가·점수 계산·저장 칸·메일 내용은 바꾸지 않는다.

## 원칙 (재리 2026-10-23)

"우리 사이트는 미니멀함, 직관적, 사용자 편의성 우선이다 명심하자." 설명 글은 줄이고 도움말·툴팁으로, 버튼 이름은 하는 일이 바로 보이게, 위험한 버튼은 눈에 띄게.

## 사용자 의견과 결정

- "키워드 타자 입력 후 엔터 누르지 않더라도 입력되어 있게끔(현재는 키 입력 후 다른 곳 클릭하면 사라짐)" → Streamlit 고르기 칸은 Enter 없이 글자를 남길 수 없음. 글자 칸 + 추천 키워드 버튼으로 바꿈(재리 확인)
- "메일 -> 공고 메일 보내기, 모아보기 -> 기술 모아보기"
- "모아보기 보기 불편함 개선 필요" → 탭 두 개, 위 10개, 이름 칸 폭 고정, 맨 위 요약 한 줄(제안 → "진행")
- "평가칸을 사이드바로 옮기는 건 제안" → 찬성 의견 → "진행"
- "사용법에 메일전송, 기술 모아보기 등 간단하게 추가 (llm키 발급방법, gmail키 발급방법도 간략하게)"
- "초기화 기능이 담긴 버튼은 마우스 커서 올려놓으면 빨간색 처럼 눈에 띄고 위협적인 색으로"
- "공고 자세히에서 기술스택란 옆 '초록은 내 프로필에 있는 기술' 삭제"
- "공고 <-> 프로필 전환 간 애니메이션" + "기타 애니메이션이 있으면 좋을 곳" → 점수 막대·도넛 채움, 카드 들림 추천(창 열림 효과는 뺌)
- "Footer 추가해서 약관이나 도움말, 제공 등 필요한 것" → 개인 도구라 법적 약관 대신 이용 안내
- "3번 창은 제외하자. 자세히 눌르면 열리는 창도 스르륵 펼쳐지며 열 수 있나?" → 창 효과는 뺌. 자세히(팝오버)는 열릴 때만 펼침(닫힐 때는 Streamlit이 바로 지움)
- "상단 자비스 이름보다 키/사용법/새로고침/메일/모아보기가 너무 큰 것 같다. 배치나 크기 더 깔끔하게" → 작은 버튼으로 오른쪽 정리

## 기능 요구사항

| ID | 내용 |
| --- | --- |
| F1 | 수집 키워드는 글자 칸. 치다가 다른 곳을 눌러도 남는다(Enter 필요 없음). 칸 아래 추천 키워드 버튼(프로필 희망 직무·주력 기술 먼저, 최대 8개)을 누르면 칸에 들어간다 |
| F2 | 위 버튼 이름: **✉ 공고 메일 보내기**, **📊 기술 모아보기**. 창 제목도 같다 |
| F3 | 기술 모아보기: 맨 위 "공고 n건 기준 · 필터" 아래 요약 한 줄("많이 찾는 기술 n개 중 내 기술 m개"). 탭 두 개 **많이 찾는 기술** / **내가 부족한 것**. 각 위 10개. 이름 칸 폭을 맞춰 막대가 같은 곳에서 시작한다 |
| F4 | 평가 줄(체크한 공고 평가, 평가 전 전부 평가)을 사이드바 맨 위로. 버튼은 위아래로. 0건이면 한 줄(v0.6.2 F17 그대로) |
| F5 | 사용법 창에 "공고 메일 보내기", "기술 모아보기" 한 줄씩. 그 아래 접힌 칸 두 개: **제미나이 API 키 받기**, **Gmail 앱 비밀번호 받기**(각 3줄 안팎, 발급 주소 링크) |
| F6 | 지우는 버튼(공고 초기화·지우기, 프로필 전체 초기화·비우기, 키 삭제, 메일 설정 삭제)은 마우스를 올리면 빨간 바탕·흰 글자 |
| F7 | 자세히 기술스택 옆 "초록은 내 프로필에 있는 기술" 글을 없앤다. 초록 칩에 마우스를 올리면 "내 프로필에 있는 기술"이 뜬다(기술 모아보기 칩도) |
| F8 | 📋 공고 ↔ 👤 프로필 탭을 바꾸면 내용이 0.2초 동안 살짝 떠오르며 나타난다 |
| F9 | 점수 도넛·항목 점수 막대·기술 모아보기 막대가 처음 그려질 때 0에서 차오른다(0.4초). 카드에 마우스를 올리면 그림자가 조금 커진다 |
| F11 | 공고 카드의 자세히(팝오버)가 열릴 때 0.2초 동안 위에서 아래로 펼쳐진다. 닫힐 때는 효과 없음 |
| F12 | 제목 오른쪽 위 버튼(키·사용법·새로고침·메일·모아보기)은 제목보다 작게: 작은 글자·얇은 여백. 1280px 창에서 글자가 잘리지 않는다 |
| F10 | 화면 맨 아래 Footer(이용 안내): 개인 사용만·수집한 공고 공유 금지(두 사이트 약관), 데이터는 이 PC에만·평가할 때만 LLM 제공자로 전송, 도움말은 위 📖 사용법, 공고 출처(사람인·잡코리아 공개 페이지)·참고(ai-job-search, MIT), 버전 |

## 비기능 요구사항

| ID | 내용 |
| --- | --- |
| N1 | 새 의존성 없음. 애니메이션·색은 CSS만 |
| N2 | 운영체제의 "움직임 줄이기"(`prefers-reduced-motion`)가 켜져 있으면 F8·F9·F11 애니메이션을 끈다 |

## 하지 않는 것

- 창(메일·모아보기·사용법)이 열릴 때의 효과. Streamlit 창 구조에 기대서 깨지기 쉬움
- 법적 이용약관·개인정보처리방침 문서. 서비스가 아닌 개인 도구
- 키워드 여러 개 한 번에 수집(지금처럼 한 번에 하나)
