# v0.7.2 요구사항

2026-10-23 확정(재리 "진행!" 02:53). v0.7.1을 써 본 의견으로 화면을 한 번 더 다듬는다. 수집·평가·점수 계산·저장 칸·메일 내용은 바꾸지 않는다. 원칙은 v0.7.1과 같음: 미니멀, 직관적, 사용자 편의성 우선.

## 사용자 의견과 결정

- "평가칸을 필터 아래에 두자"
- "사이드바 스크롤 생기지 않도록 크기 조절. DB공고 많이 줄이고 설명을 텍스트 위에 올리면 나오게" → 설명 글은 도움말(?)로
- "평가 전 공고만 보기 필터 추가" → 토글이 6개가 되어 길어짐. 토글을 "보기" 고르기 칸 하나로 합침(제안 → "진행")
- "추천 키워드 기준 모호(프로필 것을 굳이 쓸 필요 없음). 추천 키워드 삭제"
- "키워드 지역처럼 여러개" → 재리 "삭제"(하지 않음)
- 소개 문장을 더 짧게, 창 크기와 상관없이 한 줄 → "채용공고를 모아 나와 비교!"(재리 "! 추가")
- Footer 줄바꿈으로 내용별 구분, "필요하면 푸터를 늘리고 푸터 가장 밑에 이스터에그를 넣자"
- "JOBVIS 더 키우고 'AI 취업비서' 삭제"
- "자세히 버튼 누르면 위로 띄워질 때가 있고 아래로 띄워질 때가 있음" → 팝오버는 그대로 두고, 누르면 화면을 그 카드 윗단까지 내려 아래로 열리게(재리 02:51 제안)
- "자세히 스크롤 내리면 자세히 칸 상단의 형광색 바와 내용이 겹쳐져 보인다!"(03:02)
- "기술 모아보기 많이 찾는 기술, 내가 부족한 것 창 크기 동일하게"(03:03)
- "평가 칸 카드의 평가 칸을 체크하고 누릅니다 설명 삭제"(03:03) → F2에서 화면 글은 없애고 버튼 도움말로만 남김
- "필터의 공고 목록에 적용 삭제"(03:04)
- "프로필 경력연수 30년까지는 너무 많다 10년까지 선택 가능하도록"(03:05)

## 기능 요구사항

| ID | 내용 |
| --- | --- |
| F1 | 사이드바 순서: 필터 → 평가 줄 → 🗑 공고 초기화 |
| F2 | 높이 900px 창에서 사이드바에 스크롤이 생기지 않는다. 평가 줄 안내 글과 공고 초기화 설명 글은 버튼 도움말(마우스를 올리면)로 옮기고, 공고 초기화는 카드 없이 버튼 하나 |
| F3 | 필터 토글 다섯 개를 고르기 칸 **보기** 하나로: 전체 · 평가된 공고 · **평가 전 공고**(새로) · 추천 이상 · 지원한 공고 · 이미지 필요 · 관심 없음. 요약 칸 버튼은 이 칸을 바꾼다 |
| F4 | 수집 키워드 칸 아래 추천 키워드 버튼을 없앤다. 칸 안 예시 글만 남김 |
| F5 | 제목 아래 문장 "채용공고를 모아 나와 비교!". 창 폭과 상관없이 한 줄 |
| F6 | JOBVIS 제목을 더 크게, 위 "✦ AI 취업 비서" 표시를 없앤다 |
| F7 | Footer를 내용별 세 줄(이용 · 데이터 · 도움말과 출처·버전)로. 맨 아래 작은 ✦에 마우스를 올리면 이스터에그 문장이 나타난다 |
| F8 | 자세히를 누르면 화면이 그 공고 카드 윗단(위 메뉴에 가리지 않는 위치)까지 움직이고 자세히는 아래로 열린다. 닫을 때는 화면이 움직이지 않는다. 목록 맨 아래 공고처럼 더 내려갈 곳이 없으면 위로 열릴 수 있다 |
| F9 | 보통 버튼(지원함·관심 없음 등)에 마우스를 올리면 바탕이 아주 살짝 라임 빛으로 바뀐다. 주 버튼·지우는 버튼 색은 그대로 |
| F10 | 자세히를 내리면 위 형광 띠가 글과 같이 올라간다. 글이 띠 밑으로 지나가 겹쳐 보이지 않는다 |
| F11 | 기술 모아보기의 두 탭 칸 높이가 같다. 탭을 바꿔도 창 크기가 변하지 않는다 |
| F12 | 사이드바 필터 제목 옆 "📋 공고 목록에 적용" 글을 없앤다 |
| F13 | 프로필 경력 연수 슬라이더는 0–10년. 저장된 값이 10보다 크면 그 값까지 늘려 값이 바뀌지 않게 한다(v0.5 F18 그대로) |
