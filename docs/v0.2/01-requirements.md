# v0.2 요구사항 (초안)

## 목표

조건(지역·직무·경력)에 맞는 사람인 공고를 여러 건 가져와 요약하고, 이미 저장한 공고는 건너뛰고 새 공고만 구글 시트에 저장한다.

## 기능 요구사항

| ID | 내용 |
| --- | --- |
| F1 | 실행 옵션으로 키워드, 지역, 직무, 경력, 가져올 개수를 받는다. 키워드 외에는 모두 선택 |
| F2 | 지역·직무·경력은 사람이 읽는 이름(예: 서울, 백엔드, 신입)으로 입력하고, 프로그램이 사람인 코드로 바꾼다 |
| F3 | 가져올 개수 기본값은 10건, 최대 110건(사람인 API 한 번 요청 한도) |
| F4 | 각 공고의 자격요건을 v0.1과 같은 방식으로 한 줄 요약한다 |
| F5 | 시트에 이미 있는 공고(사람인 공고 ID 기준)는 다시 저장하지 않는다 |
| F6 | 시트에 공고 ID와 저장 시각 열을 추가한다 |
| F7 | 실행이 끝나면 가져온 수, 새로 저장한 수, 건너뛴 수를 출력한다 |

## 비기능 요구사항

| ID | 내용 |
| --- | --- |
| N1 | v0.1의 N1~N4(키 관리, 무료 개발, 모델 교체, 서버 없음)를 그대로 지킨다 |
| N2 | 이미 저장된 공고는 AI 요약도 하지 않는다 (무료 사용량 절약) |
| N3 | 공고 하나의 요약이 실패해도 나머지는 계속 처리하고, 실패한 공고는 출력에 남긴다 |
| N4 | 가짜 데이터 테스트를 `tests/`에 pytest로 둔다 |

## 하지 않는 것

- 학력·고용형태 필터
- 메일 알림, 웹 화면
