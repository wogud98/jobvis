# v0.6.1 요구사항

2026-10-22 확정(사용자 "진행"). v0.6을 재리 PC에서 써 본 의견으로 화면을 다듬는다. 수집·평가 방식, 점수 계산, 저장 칸은 바꾸지 않는다.

## 사용자 의견 (2026-10-22)

- 메인: "JOBVIS 색이 너무 어두움, 크기 작음 -> 하얀색 수정", "LLM 키 입력칸이 너무 큼, 화면 제목, 설명과 너무 가까움"
- 공고: "수집칸 (사람인·잡코리아 공개 페이지, 요청 간격 3초) 안내 삭제", "평가 전 평가 체크박스, 텍스트가 창 크기에 따라서 잘림", "수집 후 자세히 토글 없어도 될듯", 수집 결과 안내("새 공고 18건을 저장했습니다 / 수집 결과 (… 시작) / 본문 없는 공고 1건 …") "없어도 될듯", "종합점수 칸 평가 있을 때만 활성화"
- 프로필: "선택한 키워드가 여러개면 무엇이 선택되었는지 보기가 어려움, 움직일 수 없음", "여러 포트폴리오 첨부 시 중복된 내용이지만 텍스트가 조금 다른 것", "각 칸(기술 경력 방향 문화)의 높이가 달라 지저분함", "이력서 포트폴리오로 채우기 칸에 text(안내)가 너무 많음"

## 기능 요구사항

### 메인

| ID | 내용 |
| --- | --- |
| F1 | 제목 JOBVIS를 크게(2.6rem → 3.4rem) 하고, 어두운 테마에서는 흰색으로 한다. 밝은 테마는 바탕이 밝아 검정을 유지한다 |
| F2 | 키 입력 칸을 작게 한다: 제목·안내 한 줄 + 입력란·저장 버튼 한 줄. 제목·소개 문장과 간격을 둔다 |

### 공고

| ID | 내용 |
| --- | --- |
| F3 | 수집 카드 제목 옆 "사람인·잡코리아 공개 페이지, 요청 간격 3초"를 지운다. 같은 내용은 사용법 창 ② 수집에 둔다 |
| F4 | 창이 좁아도 카드의 평가 체크 글자·점수·지원함/관심 없음 버튼과 평가 줄 버튼 글자가 잘리지 않는다. 체크와 점수는 한 칸에 위아래로 둔다 |
| F5 | 수집·평가·받은함이 끝나면 결과 한 줄과 할 일을 잠깐 뜨는 알림으로 한 번 보인다. 화면에 남는 결과 칸은 없다. 문제(사이트 멈춤, 실패)가 있을 때만 빨간 칸과 접힌 자세히를 보인다. 실행 오류는 지금처럼 빨간 칸 |
| F6 | 종합점수 TOP 5 칸은 점수 있는 공고가 있을 때만 보인다 |

### 프로필

| ID | 내용 |
| --- | --- |
| F7 | 고르기 칸에 고른 키워드가 많으면 옆으로 숨기지 않고 줄을 바꿔 모두 보인다(프로필 칸, 수집 카드 사이트 칸 모두) |
| F8 | 이력서로 채울 때 같은 항목이 여러 번 들어가지 않는다: LLM에 "여러 파일의 같은 항목은 하나로" 규칙을 주고, 띄어쓰기·대소문자만 다른 항목은 코드에서 하나만 남긴다 |
| F9 | 기술·경력, 방향·문화 칸은 같은 줄끼리 높이를 맞춘다 |
| F10 | 이력서 채우기 칸의 글을 줄인다: 제목 한 줄, 형식·전송 안내는 파일 칸 ? 도움말로, 채우기 버튼과 "이미 적은 칸도 바꾸기"를 한 줄에 |

## 비기능 요구사항

| ID | 내용 |
| --- | --- |
| N1 | 테스트는 실제 LLM·사이트 없이 돈다. 바뀐 결과 표시(F5), 차트(F6), 키 칸(F2), 중복 합치기(F8)를 테스트한다 |
| N2 | 화면 모양(F1, F4, F7, F9)은 브라우저로 넓은 창·좁은 창, 밝은·어두운 테마에서 확인한다 |

## 하지 않는 것

- 시작 파일·OCR 분리는 v0.6.2 ([v0.6.2 요구사항](../v0.6.2/01-requirements.md))
- 키 보안 강화(오류 문구 가리기, 키 삭제 등)는 사용자 결정 뒤
